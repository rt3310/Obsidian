### 파일 출력
```c
/* a.txt 에 내용을 기록한다. */
#include <stdio.h>

int main() {
	FILE *fp;
	fp = fopen("a.txt", "w");
	
	if (fp == NULL) {
		printf("Write Error!!\n");
		return 0;
	}
	
	fputs("Hello World!!! \n", fp);
	
	fclose(fp);
	return 0;
}
```
위 코드를 실행시키면 `a.txt` 파일이 생성된 것을 볼 수 있다.

우리가 하드디스크에 저장되어 있는 파일들을 자유롭게 이용할 수 있다고는 하나, 이를 쓰는 과정은 매우 복잡할 것이다. 왜냐하면 파일을 새로 만든다고 쳐도, 하드디스크 어떤 부분에 파일을 새로 만들어야 할지, 얼마나 크게 파일을 만들 수 있는지 등의 모든 것을 고려해야 한다.
다행히 운영체제에서 이를 알아서 해준다.

`fopen` 함수는 위에서 말한 '운영체제가 알아서 해주는 부분'을 처리한다. `fopen` 함수는 우리가 지정한 파일(a.txt)와 소통할 수 있도록 스트림을 만들어 준다.

### 스트림
![[154733414D1894062D76CF.webp]]
우리가 `printf` 함수를 이용할 때 어떤 작업이 컴퓨터에서 내부적으로 처리되는지 생각해보자.

먼저, 출력할 문자열을 구성해야하고 이를 모니터에 전달해서 출력하라는 명령을 내리게 해야한다.
이를 쉽게할 수 있는 이유는 **스트림**에 있다. 스트림은 이 두 개의 완전히 다른 장치들을 이어주는 파이프라고 보면 된다.
이러한 스트림은 우리가 직접 구현해야 되는 것이 아니라 운영체제가 스스로 처리해 주는 것이다.
만약 우리가 모니터와 잇는 스트림을 이용한다면 운영체제는 모니터에 맞는 명령을 내릴 것이고, 키보드와 잇는 스트림을 이용한다면 운영체제가 키보드에 맞는 명령을 알아서 내릴 것이다.
