```cpp
#include <iostream>
#include <string>

class Base {
	std::string s;

public:
	Base() : s("기반") { std::cout << "기반 클래스" << std::endl; }
	
	void what() { std::cout << s << std::endl; }
};
class Derived : public Base {
	std::string s;

public:
	Derived() : s("파생"), Base() { std::cout << "파생 클래스" << std::endl; }
	
	void what() { std::cout << s << std::endl; }
};
int main() {
	std::cout << " === 기반 클래스 생성 ===" << std::endl;
	Base p;
	
	p.what();
	
	std::cout << " === 파생 클래스 생성 ===" << std::endl;
	Derived c;
	
	c.what();
	
	return 0;
}
```
위 코드를 성공적으로 컴파일했다면,
```
 === 기반 클래스 생성 ===
기반 클래스
기반
 === 파생 클래스 생성 ===
기반 클래스
파생 클래스
파생
```
`Base`에서 `what`을 호출하면 당연히 `Base`의 `what`이 실행되어서 '기반'이라고 나오고, `Base`를 상속받는 `Derived` 클래스에서 `what`을 호출하면, `Derived`의 `what`이 `Base`의 `what`을 override해서 `Derived`의 `what`이 호출되게 된다.

이번에는 코드를 약간 변형해보자.
```cpp
#include <iostream>
#include <string>

class Base {
	std::string s;
	
public:
	Base() : s("기반") { std::cout << "기반 클래스" << std::endl; }
	
	void what() { std::cout << s << std::endl; }
};
class Derived : public Base {
	std::string s;
	
public:
	Derived() : s("파생"), Base() { std::cout << "파생 클래스" << std::endl; }
	
	void what() { std::cout << s << std::endl; }
};
int main() {
	Base p;
	Derived c;
	
	std::cout << "=== 포인터 버전 ===" << std::endl;
	Base* p_c = &c;
	p_c->what();
	
	return 0;
}
```
성공적으로 컴파일 했다면,
```
기반 클래스
기반 클래스
파생 클래스
=== 포인터 버전 ===
기반
```
이번에는 `Derived`의 객체 `c`를 `Base` 객체를 가리키는 포인터에 넣었다.

```cpp
Base* p_c = &c;
```
`Derived` 객체 `c`도 어떻게 보면 `Base` 객체이기 때문에 `Base` 객체를 가리키는 포인터가 `c`를 가리켜도 무방하다.
![[Pasted image 20260731000454.png]]
그 대신 `p`는 엄연히 `Base` 객체를 가리키는 포인터이다. 따라서, `p`의 `what`을 실행한다면 `p`는 당연히 '`Base`의 `what`을 실행해주어야 겠구나'하고, `Base`의 `what`을 실행해서, `Base`의 `what`은 `Base`의 `s`를 출력하게 된다.

이러한 형태의 캐스팅을 **업캐스팅**이라고 부른다.
![[Pasted image 20260731000608.png]]

그럼 다운캐스팅도 있을까? 다음 코드를 컴파일 해보자.
```cpp
#include <iostream>
#include <string>

class Base {
	std::string s;
	
public:
	Base() : s("기반") { std::cout << "기반 클래스" << std::endl; }
	
	void what() { std::cout << s << std::endl; }
};
class Derived : public Base {
	std::string s;
	
public:
	Derived() : s("파생"), Base() { std::cout << "파생 클래스" << std::endl; }
	
	void what() { std::cout << s << std::endl; }
};
int main() {
	Base p;
	Derived c;
	
	std::cout << "=== 포인터 버전 ===" << std::endl;
	Derived* p_p = &p;
	p_p->what();
	
	return 0;
}
```
컴파일한다면 아래와 같은 오류 메시지가 나온다.
```
error C2440: 'initializing' : cannot convert from 'Base *' to 'Derived *'
```

이는
![[Pasted image 20260731000719.png]]
만일 `Derived*` 포인터가 `Base` 객체를 가리킨다고 했을 때, `p_p->what()`을 하게 된다면 `Derived`의 `what` 함수가 호출되어야 하는데, 이는 불가능하기 때문이다.
왜냐면, `p_p`가 가리키는 객체는 `Base` 객체이므로 `Derived`에 대한 정보가 없다. 따라서, 이와 같은 문제를 막기 위해서 컴파일러 상에서 함부로 다운 캐스팅 하는 것을 금지하고 있다.

그럼 만약 다음과 같은 상황은 어떨까?
```cpp
#include <iostream>
#include <string>

class Base {
	std::string s;
	
public:
	Base() : s("기반") { std::cout << "기반 클래스" << std::endl; }
	
	void what() { std::cout << s << std::endl; }
};
class Derived : public Base {
	std::string s;
	
public:
	Derived() : s("파생"), Base() { std::cout << "파생 클래스" << std::endl; }
	
	void what() { std::cout << s << std::endl; }
};
int main() {
	Base p;
	Derived c;
	
	std::cout << "=== 포인터 버전 ===" << std::endl;
	Base* p_p = &c;
	
	Derived* p_c = p_p;
	p_c->what();
	
	return 0;
}
```
컴파일 하면 전과 같은 에러가 뜬다.

하지만 우리는 `p_p`가 가리키는 것이 `Derived`라는 것을 알고 있다. 때문에 비록 `Base *` 포인터를 다운캐스팅 함에도 불구하고 `p_p`가 실제로는 `Derived` 객체를 가리키기 때문에
```cpp
Derived* p_c = p_p;
```
를 해도 전혀 문제가 없다.

위 코드의 타입 변환을 위해서는 아래처럼 강제적으로 변환을 하면 된다.
```cpp
Derived* p_c  = static_cast<Derived*>(p_p);
```
약간은 위험하지만(만약 `p_p`가 `Derived` 객체를 가리키지 않는다면), 컴파일 에러르 발생시키지 않고 성공적으로 컴파일 할 수 있다.
그렇다면 만일 `p_p`가 `Base`객체를 가리키는데 강제적으로 타입 변환을 해서 `what`을 실행하면 어떻게 될까?

```cpp
#include <iostream>
#include <string>

class Base {
	std::string s;
	
public:
	Base() : s("기반") { std::cout << "기반 클래스" << std::endl; }
	
	void what() { std::cout << s << std::endl; }
};
class Derived : public Base {
	std::string s;
	
public:
	Derived() : s("파생"), Base() { std::cout << "파생 클래스" << std::endl; }
	
	void what() { std::cout << s << std::endl; }
};
int main() {
	Base p;
	Derived c;
	
	std::cout << "=== 포인터 버전 ===" << std::endl;
	Base* p_p = &p;
	
	Derived* p_c = static_cast<Derived*>(p_p);
	p_c->what();
	
	return 0;
}
```
위 코드를 컴파일하고 실행시켜 보면 런타임 에러가 나는 것을 볼 수 있다.

이런 강제적인 다운 캐스팅의 경우, 컴파일 타임에서 오류를 찾아내기 힘들기 때문에 다운 캐스팅은 작동이 보장되지 않는 한 매우 권장하지 않는다.

### dynamic_cast
이러한 캐스팅에 따른 오류를 미연에 방지하기 위해, C++에서는 상속 관계에 있는 두 포인터들 간에 캐스팅을 해주는 `dynamic_cast`라는 것을 지원한다. 이를 사용하는 방법은 `static_cast`와 거의 동일하다.

하지만 위의 코드의 경우 컴파일 하면,
```cpp
Derived* p_c = dynamic_cast<Derived*>(p_p);
```
다음과 같이 캐스팅 할 수 없다는 컴파일 에러가 발생한다.
```
test.cc: In function 'int main()':
test.cc:27:44: error: cannot dynamic_cast 'p_p' (of type 'class Base*') to type 'class Derived*' (source type is not polymorphic)
   Derived* p_c = dynamic_cast<Derived*>(p_p);
```
