구조체는 "각 원소의 타입이 제각각인 배열"과 같다.
```c
struct Human {
	int age;
	int height;
	int weight;
};
```
이 때문에 배열에서는 배열의 타입만으로 모든 원소의 타입을 알 수 있었지만 구조체는 그렇지 않다.
따라서 구조체는 정의할 때 **모든 원소의 타입을 명시해주어야 한다**.

### 초기화
구조체의 정의 내부에서는 변수를 초기화할 수 없다.
```c
#include <stdio.h>
struct Books {
	char name[30];
	char auth[30];
	char publ[30];
	int borrowed;
};
int main() {
	struct Books book_list[3];
	int i;
	
	for (i = 0; i < 3; i++) {
		scanf("%s%s%s", book_list[i].name, book_list[i].auth, book_list[i].publ)
		book_list[i].borrowed = 0;
	}
	
	return 0;
}
```

```c
struct Books book_list[3];
```
먼저 위 문장을 살펴보자.
`int arr[3]`에서 `int`가 하나의 타입이듯이, `struct Books`가 하나의 타입이라고 생각하면 된다.
그런데, `int arr[3]`을 하면 `arr`에 `int` 형 원소가 3개 만들어지듯이, `book_list` 배열에는 `struct Books` 형의 변수가 3개 만들어지는 것이다.
