`int` 자료형을 감싸는 int Wrapper 클래스를 구현한다 해보자. 그럼 다음과 같이 작성해볼 수 있다.
```cpp
class Int
{
	int data;
	// some other data
	
public:
	Int(int data) : data(data) {}
	Int(const Int& i) : data(i.data) {}
};
```

이를 `int`와 똑같이 동작하도록 만들고 싶을 것이다.
```cpp
Int x = 3;
int a = x + 4;
```

하지만, 수 많은 연산자들을 일일히 오버로딩하는 것은 힘들 것이다.
`int` 형 변수끼리 하는 일과 정확히 똑같기 때문에 굳이 이미 제공하는 기능을 다시 만들어야 하냐는 의문이 생길 수 있다.

그렇다면 그냥 이 Wrapper 클래스의 객체를 마치 '`int` 형 변수'라고 컴파일러가 생각하도록 하면 된다.
이때 타입 변환 연산자를 사용한다.

만약 컴파일러가 이 클래스의 객체를 `int` 형 변수로 변환할 수 있다면, `operator+` 등을 정의하지 않더라도 컴파일러가 가장 이 객체를 `int` 형 변수로 변환한 다음에 `+`를 수행할 수 있기 때문이다.

타입 변환 연산자는 다음과 같이 정의한다.
```
operator (변환하고자 하는 타입) ()
```

예를 들어, int wrapper 클래스의 경우 다음과 같은 타입 변환 연산자를 정의할 수 있다.
```cpp
operator int()
```
한 가지 주의할 점은, 생성자처럼 함수의 반환타입을 써주면 안된다는 것이다.
이는 C++에서 변환 연산자를 정의하기 위한 언어 상의 규칙이라고 볼 수 있다. 때문에 다음과 같이 그냥 `data`를 반환해주면 된다.
```cpp
operator int() { return data; }
```
이렇게 되면 wrapper 클래스의 객체를 읽는데에는 아무 문제가 없게 된다.
다만, 대입 시에 문제가 발생할 수 있다. 다행히 디폴트 대입 연산자가 잘 처리할 것이기 때문에 걱정하지 않아도 된다.

```cpp
#include <iostream>

class Int {
	int data;
	// some other data
	
public:
	Int(int data) : data(data) {}
	Int(const Int& i) : data(i.data) {}
	
	operator int() { return data; }
};
int main() {
	Int x = 3;
	int a = x + 4;
	
	x = a * 2 + x + 4;
	std::cout << x << std::endl;
}
```
