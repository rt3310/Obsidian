전위/후위 증감 연산자는 그 함수의 형태가 다르며 컴파일러가 함수의 형태로 구분하게 된다.

### 전위 증감 연산자
```cpp
operator++();
operator--();
```

**값이 바뀐 자기 자신**을 반환해야 한다.
```cpp
A& operator++() {
	// A++을 수행한다.
	return *this;
}
```

### 후위 증감 연산자
```cpp
operator++(int x);
operator--(int x);
```
여기서 인자 `x`는 아무런 의미가 없다. 단지 컴파일러 상에서 전위와 후위를 구별하기 위해 int 인자를 넣어주는 것이다.

실제로 `++`를 구현하면서 인자로 들어가는 값을 사용하는 경우는 없기 때문에 다음과 같이 해도 무방하다.
```cpp
operator++(int);
operator--(int);
```

**값이 바뀌기 이전의 객체**를 반환해야 한다.
```cpp
A operator++(int) {
	A temp(A);
	// A++을 수행한다.
	return temp;
}
```
`++`을 하기 전에 객체를 반환해야 하므로, `temp` 객체를 만들어서 이전 상태를 기록한 후에, `++`을 수행한 뒤 `temp` 객체를 반환하게 된다.

따라서 **후위 증감 연산의 경우 추가적으로 복사 생성자를 호출하기 때문에 전위 증감 연산보다 더 느리다**.
