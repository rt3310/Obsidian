```c
/* 문자열 */
#include <stdio.h>
int main() {
	char str[] = "sentence";
	char *pstr = "sentence";
	
	printf("str : %s \n", str);
	printf("pstr : %s \n", pstr);
	
	return 0;
}
```
성공적으로 컴파일 했다면
```
str : sentence 
pstr : sentence
```
와 같이 나온다.

여기서
```c
char str[] = "sentence";
char *pstr = "sentence";
```
첫번째 문장은 평범하지만 아래는 이상하게 보일 수 있다. `char`형을 가리키는 포인터이므로 `char` 형 변수의 주소값이 들어가야 하기 때문이다.

그런데 `"sentence"`를 주소값 마냥 사용하고 있다. 그렇다. "sentence"는 주소 값이다.
```c
print("%d \n", "sentence");
```
위 문장을 실행해보면 특정한 수가 출력됨을 알 수 있다.

그럼 "sentence"는 무엇일까? 그 전에 다음 코드를 보자.
```c
/* 문자열 */
#include <stdio.h>
int main() {
	char str[] = "hello";
	char *pstr = "goodbye"; // 최신 c++에서는 const 없이 허용하지 않는다.
	
	str[1] = 'a';
	pstr[1] = 'a';
	
	return 0;
}
```
위 코드는 오류가 나는 것을 확인할 수 있는데, 
```c
pstr[1] = 'a';
```
가 문제인 것을 확인할 수 있다. 즉, 상수처럼 값의 변경을 허락하지 않는 것처럼 보인다.

## 리터럴(literal)

리터럴이란 소스코드 상에서 고정된 값을 가지는 것을 일컫는다. 특히, C 언어의 경우 큰 따옴표(")로 묶인 것들을 문자열 리터럴(string literal)이라 부른다.

```c
char *pstr = "goodbye";
printf("why so serious?");
scanf("%c", str[0]);
```
그렇다면 위 3 개의 문장에서 문자열 리터럴은 무엇일까? `goodbye, why so serious, %c` 모두 리터럴이 된다.

컴퓨터는 이러한 리터럴들을 따로 모아서 보관한다. 즉, 프로그램을 실행하면 메모리 상의 특별한 곳에 `goodbye, why so serious, %c` 와 같은 리터럴들이 보관되어 있는 공간이 생긴다는 것이다

> [!info]
> 프로그램이 실행돼서 메모리에 로드되면, 5 가지 종류의 영역(text segment, data segment, bss segment, heap, stack) 이 존재한다. 
> 이 때, 텍스트 세그먼트(text segment) 에 프로그램 코드와 상수, 리터럴 등이 여기서 정의된다. 왜냐하면 텍스트 세그먼트에 있는 내용들은 읽기만 가능하기 때문이다. 물론 이 사실은 컴파일러 구현에 따라, 사용하는 운영체제 환경에 따라서 다를 수 있다.

`char *pstr = "goodbye";` 을 실행하게 되면 컴퓨터는 "goodbye 의 시작 주소값 좀 가져와서 `pstr` 에 대입좀 해라" 라는 의미의 작업을 실행한다. 따라서, `pstr` 은 "goodbye" 라는 리터럴을 가리키고 `printf("%s", pstr)` 을 했을 때 `goodbye` 를 성공적으로 출력할 수 있게 되었던 것이다.

리터럴이 보관되는 곳은 오직 읽기만 가능한 곳이 된다. 만일 이곳을 함부로 변경하려고 하는 시도가 있다면 바로 프로그램이 강제로 종료되게 된다.
> [!info]
> 사용하는 운영체제, 환경에 따라 다르다.


### 문자열 결합/비교
```cpp
char str1[] = {"abc"};
char str2[] = {"def"};
str1 = str1 + str2;
```
이렇게 한다고 해서 str1이 "abcdef"가 되지 않는다.
`str1 + str2`는 각 배열의 주소 값을 더하는 것인데, 배열의 이름은 포인터 상수이기 때문에 대입 연산을 수행할 경우 오류가 나게 된다.

뿐만 아니라 다음과 같이 문자열을 비교하는 것도 불가능하다.
```cpp
if (str1 == str2)
```
왜냐하면 위 문장의 의미는 "`str1`의 문자열이 들어있는 메모리 상의 (시작)주소와 `str2`의 문자열이 들어있는 메모리 상의 (시작)주소 값을 비교해라" 라는 의미의 문장이기 때문이다.
물론 다음과 같은 문장도 원하는 대로 실행이 되지 않는다.
```cpp
if (str1 == "abc")
```
"abc"는 리터럴이다. 즉, `str1`과 "abc"를 비교한다는 뜻은 "str1이 저장된 메모리 상의 주소값과 `abc`라는 문자열 리터럴이 보관된 메모리 상의 주소값을 비교"하는 문장이다.

```cpp
str1 = str2;
```
위 구문도 실행되지 않는다. `str1`은 값이 바뀔 수 없는 포인터 상수이기 때문에 오류가 발생하게 된다.

때문에 다음과 같은 함수들이 필요하다.
- 문자열 내의 총 문자의 수를 세는 함수
- 문자열을 복사하는 함수
- 문자열을 합치는 함수
- 문자열을 비교하는 함수

### 문자열 복사 함수
```c
int copy_str(char *dest, char *src) {
	while (*src) {
		*dest = *src;
		src++;
		dest++;
	}
	*dest = '\0';
	
	return 1;
}
```
먼저 `while` 문을 살펴보면 조건이 `*src`인 것을 볼 수 있다. 문자열을 다룰 때 많이 쓰는 방법인데, `NULL` 문자의 값이 0이므로 `*src`가 `NULL` 문자에 도달하기 전까지 `while` 문이 계속 돌아가게 된다.

그리고 `*dest = *src`를 통해서 `src`의 문자를 `dest`에 대입하였다. 그리고 `src`와 `dest`를 각각 1씩 증가시켰는데, 포인터에 1을 더하면 포인터가 가리키는 타입의 크기를 곱한 만큼 증가한다.

```c
*dest = '\0';
```
마지막으로 `dest`에 '\0', 즉 `NULL` 문자를 집어넣었다. 아까 위의 `while` 문에서 `src`가 `NULL`이 된다면 `while` 문을 종료해 버렸기 때문에 `src`에 넣을 틈이 없었는데 마지막에 위와 같이 처리해줌으로써 `dest`에 `NULL` 문자를 끝부분에 삽입할 수 있게 되었다.

하지만 위 함수는 `dest`의 크기가 `src`의 크기보다 큰지 작은지 검사하지 않기 때문에 위험하다.
만약 `dest`의 크기가 `src`보다 작다면 메모리의 허락되지 않는 공간까지 침범하므로 큰 문제를 야기할 수 있다.

그런데 다음 코드는 안되는 것일까?
```cpp
char str[100];
str = "abcdefg";
```
그러나 이 방법으로 컴파일하게 되면 아래와 같은 오류가 발생한다.
```
error C2106: '=' : 왼쪽 피연산자는 l-value이어야 합니다.
```
위 구문에서 `str = "abcdefg"`라는 문장은 'str 에 문자열 리터럴 `abcdefg`가 위치한 곳의 주소값을 넣어라' 라는 말이다.
그런데, 배열 이름은 상수이다. 즉, 배열의 주소값을 바꿀 수 없다는 말이다.

따라서, 위와 같은 코드는 상수에 값을 대입하는 의미이기 대문에 오류가 발생하게 된다.
그러면 다음 문장은 왜 되는걸까?
```c
char str[100] = "abcdefg";
```
이는 단순히 C언어에서 사용자의 편의를 위해 제공하는 방법이라 생각하자
오직 배열을 정의할 때 사용할 수 있는 방법이다.

### 문자열 비교 함수
```c
int compare(char *str1, char *str2) {
	while (*str1) {
		if (*str1 != *str2) {
			return 0;
		}
		
		str1++;
		str2++;
	}
	
	if (*str2 == '\0') return 1;
	
	return 0;
}
```
위 함수는 일단 `while`문에서 `str1`의 끝에 도달할 때까지 각 문자들을 비교한다. 만일 한 문자라도 다르다면 `if`문에 의해 0이 반환되고 함수는 종료된다.

만약 여기서, `str1`과 `str2`가 `str1`의 부분만 일치했다면 어떨까? 다시 말해 `str1`은 "abc"이지만 `str2`는 "abcd"라면? 그러면 `while` 문에서 검사할 때 `str1`이 끝날 때까지만 검사하므로 `while`문을 잘 통과하게 된다.
따라서 `str1`이 끝났을 때 `str2`도 끝났는지 확인해 볼 필요성이 있다.
```c
if (*str2 == '\0') return 1;
```
따라서 위 문장을 추가해줌으로써 우리는 `str2`가 끝이 났는지 확인할 수 있게 된다.
만약 `*str2`가 \0이 아니라면, 즉 `str2`가 끝난 것이 아니라면 `str1`과 `str2`는 다른 것이 되므로 함수는 0을 반환하게 된다.
