배열을 정할 때 그 크기는 언제나 컴파일 시간에 확정되어 있어야 한다. 즉, 컴파일러가 배열의 크기를 추측할 필요 없이 명확하게 나타나 있어야 한다는 것이다.

하지만 동적 메모리 할당을 통해 수를 입력받고 그 수 만큼 배열의 크기를 지정할 수 있다.
```c
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char **argv) {
	int SizeOfArray;
	int *arr;
	
	printf("만들고 싶은 배열의 원소의 수 : ");
	scanf("%d", &SizeOfArray);
	
	arr = (int *)malloc(sizeof(int) * SizeOfArray);
	// int arr[SizeOfArray] 와 동일한 작업을 한 크기의 배열 생성
	
	free(arr);
	
	return 0;
}
```

위 코드에서 동적 메모리 할당을 하는 부분은 다음과 같다.
```c
arr = (int *)malloc(sizeof(int) * SizeOfArray);
```
이 함수는 <stdlib.h>에 정의되어 있다.
인자로 전달된 크기의 바이트 수 만큼 메모리 공간을 만든다. 즉, 메모리 공간을 할당하게 되는 것이다.
원소의 개수가 `SizeOfArray`인 `int` 형 배열을 만들기 위해서는 당연히 `(int의 크기) * (SizeOfArray)`가 되어야 한다. 이 때, `int` 타입의 크기를 정확하게 알기 위해서 `sizeof` 키워드를 사용하게 된다.

이 함수는 자신이 할당한 메모리의 시작 주소를 반환한다. 이 때, 반환형이 `(void *)`형 이므로 우리는 이를 `(int *)` 형으로 형변환하여 `arr`에 넣어주기만 하면 된다.

```c
free(arr);
```
그리고 마지막에 위와 같이 `free`를 통해 할당 받은 메모리 영역을 다시 컴퓨터에게 돌려준다.

만약 `free`를 제대로 하지 않으면 메모리 누수(memory leak) 문제가 발생할 수 있다.

### 할당 위치
`malloc`은 메모리 영역 중 힙(Heap)이라는 곳에 할당된다. 메모리의 힙 부분은 사용자가 자유롭게 할당하거나 해제할 수 있다.

### 2차원 배열 동적 할당

2차원 배열을 동적으로 할당하는 방법으로 크게 2가지를 생각할 수 있다.
- 포인터 배열을 사용해서 2차원 배열처럼 동작하는 배열을 만드는 방법
- 실제로 2차원 배열 크기의 메모리를 할당한 뒤 2차원 배열 포인터로 참조하는 방법

#### 포인터 배열을 사용해서 2차원 배열 할당하기
```c
/* 2 차원 배열의 동적 할당 */
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char **argv) {
	int i;
	int x, y;
	int **arr;  // 우리는 arr[x][y] 를 만들 것이다.
	
	printf("arr[x][y] 를 만들 것입니다.\n");
	scanf("%d %d", &x, &y);
	
	arr = (int **)malloc(sizeof(int *) * x);
	// int* 형의 원소를 x 개 가지는 1 차원 배열 생성
	
	for (i = 0; i < x; i++) {
		arr[i] = (int *)malloc(sizeof(int) * y);
	}
	
	printf("생성 완료! \n");
	
	for (i = 0; i < x; i++) {
		free(arr[i]);
	}
	free(arr);
	
	return 0;
}
```
포인터 배열이라 하면, 배열의 각 원소들이 모두 포인터인 배열이다.
따라서, 각 원소들이 다른 일차원 배열들을 가리킬 수 있다. 따라서 우리가 해야할 일은 먼저 포인터 배열을 동적으로 할당한 뒤에 다시 포인터 배열의 각각의 원소들이 가리키는 일차원 배열을 다시 동적으로 할당해주면, 마치 2차원 배열을 만든 것과 같은 효과를 낼 수 있다.

우리가 만든 배열은 `arr`의 원소들이 가리키는 메모리 공간이 연달아 존재한다고 보장할 수 없다.
또 포인터 배열은 2차원 배열과는 달리 다음과 같이 함수의 인자로 손쉽게 넘길 수 있다.
```c
int array(int **array);
```
이게 가능한 이유는 우리가 만든 배열은 1차원 배열들이지 2차원 배열이 아니기 때문이다.
`arr`은 단순히 `int*` 형 원소들을 가지는 1차원 배열이다. 1차원 배열을 함수의 인자로 넘겨줄 때 크기를 써주지 않았던 것처럼 같은 성격을 띈다.

하지만 그렇다고 2차원 배열의 성질을 잃어버리는 것은 아니다. 이 배열도 2차원 배열처럼 `arr[3][4]`와 같이 원소에 접근할 수 있다.

해제할 경우에는 할당하는 순서와 정 반대로 하면 된다. 만약 `arr`을 먼저 해제하면 `arr[i]`들이 메모리 상에서 사라지게 되므로 `arr[i]`들이 가리키고 있던 `int` 배열들을 해제할 수 없게 되므로 오류가 나게 된다.

#### 진짜 2차원 배열 할당하기

> [!warning]
> 이 방법은 Visual Studio에서는 작동하지 않는다. Visual Studio의 C 컴파일러가 VLA를 지원하지 않기 때문이다. 하지만 GCC나 Clang 같은 컴파일러에서는 사용 가능한 방법이다.
> 참고로 VLA는 C99에 표준으로 들어갔지만, Visual Studio의 C 컴파일러는 C90을 사용하고 있다.

위 방식으로는 진짜 2차원 배열처럼 메모리에 연속적으로 존재하는 배열을 만들 수는 없다.

따라서 메모리에 연속적으로 존재하는 진짜 2차원 배열을 만들기 위해서는 반드시 `malloc`을 통해 해당 크기의 공간을 할당해야 한다.

예를 들어,
```c
int arr[height][width];
```
와 같이 생긴 배열을 할당하고자 한다 하자. 이 경우 필요한 메모리의 크기는
```c
height * width * sizeof(int)
```
가 된다. 이렇게 메모리를 할당했으면, 이제 '해당 메모리를 2차원 배열이라고 생각해라'라고 컴파일러에게 알려줘야 한다. 따라서 이 경우 해당 메모리 주소값을 2차원 배열을 가리키는 포인터에 전달하면 된다.

2차원 배열 포인터의 경우 포인터 연산을 수행하기 위해선 반드시 포인터 타입 안에 행 길이가 들어가야 한다.
```c
int (*arr)[width] = (int (*)[width])malloc(height * width * sizeof(int));
```
이제 `arr`은 컴파일러 입장에서 행의 크기가 width인 2차원 배열을 가리키는구나 라고 생각할 수 있다.
한 가지 주의해야 할 점은 `arr`을 정의할 때 반드시 `width`에 실제 배열의 넓이 값이 들어간 후에 정의해야 한다.
예를 들어,
```c
int width;
int (*arr)[width] = (int (*)[width])malloc(height * width * sizeof(int));
scanf("%d", &width);
```
를 하게 되면 `arr`이 제대로 2차원 배열을 참조할 수 없다.
반드시
```c
int width;
scanf("%d", &width);
int (*arr)[width] = (int (*)[width])malloc(height * width * sizeof(int));
```
와 같이 `width`에 실재 2차원 배열의 행 길이가 들어간 후에 배열 포인터를 선언해야 한다.

`arr`의 모든 데이터가 메모리에 연속적으로 있으므로 `free`역시 `arr`에 대해 딱 한 번만 수행하면 된다.
```c
#include <stdio.h>
#include <stdlib.h>

int main() {
	int width, height;
	printf("배열 행 크기 : ");
	scanf("%d", &width);
	printf("배열 열 크기 : ");
	scanf("%d", &height);
	
	int(*arr)[width] = (int(*)[width])malloc(height * width * sizeof(int));
	for (int i = 0; i < height; i++) {
		for (int j = 0; j < width; j++) {
			int data;
			scanf("%d", &data);
			arr[i][j] = data;
		}
	}
	for (int i = 0; i < height; i++) {
		for (int j = 0; j < width; j++) {
			printf("%d ", arr[i][j]);
		}
		printf("\n");
	}
	
	free(arr);
}
```

한 가지 주의할 점은 위 배열 포인터를 다른 함수에 인자로 전달할 때이다.
예를 들어, 배열의 모든 원소들을 출력하는 함수를 만들고 싶다고 해보자. 그럼 다음과 같이 함수를 작성할 수도 있을 것이다.
```c
void print_array(int (*arr)[width], int width, int height) {
	for (int i = 0; i < height; i++) {
		for (int j = 0; j < width; j++) {
			printf("%d ", arr[i][j]);
		}
		printf("\n");
	}
}
```
하지만 문제가 있는데, 컴파일러가 배열의 정의인 `int (*arr)[width]`를 보고 `width`가 뭔지 알 수 없다는 것이다.
실제로 아래와 같이 컴파일 오류가 발생한다.
```
test.c:12:29: error: ‘width’ undeclared here (not in a function)
   12 | void print_array(int (*arr)[width], int width, int height) {
```
해결책은 간단한데, 컴파일러가 `arr`의 정의를 볼 때 `width`의 정체를 알 수 있도록, `width`가 `arr`의 정의 앞으로 오도록 순서를 바꿔주면 된다.
```c
void print_array(int width, int (*arr)[width], int height) {
	for (int i = 0; i < height; i++) {
		for (int j = 0; j < width; j++) {
			printf("%d ", arr[i][j]);
		}
		printf("\n");
	}
}
```
실제로 컴파일 해보면 잘 작동함을 알 수 있다.

### 어떤 방식을 사용?
되도록이면 연속된 공간에 2차원 배열을 할당하는 후자의 방법을 취하는 것이 좋다.
- `malloc` 은 상당히 느린 함수들 중에 하나이다. 따라서 `malloc`의 호출 횟수를 최소한으로 하는 것이 좋다. 따라서 배열의 높이만큼 `malloc`을 호출해야 하는 전자의 방법은 `height`가 커질수록 상당히 느려진다.
- 전자의 방법으로 메모리의 원소에 접근하기 위해서는 두 단계의 메모리 접근이 필요하다. 예를 들어, `arr[3][2]`의 경우 먼저 `arr[3]`을 읽은 뒤에, 해당 주소에서 다시 `[2]` 연산을 해야 한다. 반면 후자의 경우 컴파일러가 다이렉트로 메모리 `arr[3][2]`에 접근할 수 있다.
- 메모리가 연속적으로 있을 경우 접근이 더 빠르다.

### memcpy
```c
#include <stdio.h>
#include <string.h>

int main() {
	char str[50] = "I love Chewing C hahaha";
	char str2[50];
	char str3[50];
	
	memcpy(str2, str, strlen(str) + 1);
	memcpy(str3, "hello", 6);
	
	printf("%s \n", str);
	printf("%s \n", str2);
	printf("%s \n", str3);
	
	return 0;
}
```
`memcpy` 함수는 메모리의 특정한 부분으로부터 얼마까지의 부분을 다른 메모리 영역으로 복사해주는 함수이다. 위와 같이 문자열을 복사하는데 사용될 수 있다.
물론 문자열 복사를 전문적으로 하는 함수는 `strcpy`이지만 위와 같이 `memcpy`함수를 사용하는 것도 나쁘지 않다.
```c
memcpy(str2, str, strlen(str) + 1);
```
위 문장은 '`str`로 부터 `strlen(str) + 1` 만큼의 문자를 `str2`로 복사해라'라는 의미이다. 이 때 `strlen`에서 마지막의 `NULL` 문자는 세지 않으므로 `str2`에 `memcpy`로 복사할 때는 1을 더한만큼을 더 복사해주어야 한다.

### memmove
```c
#include <stdio.h>
#include <string.h>

int main() {
	char str[50] = "I love Chewing C hahaha";
	
	printf("%s \n", str); // I love Chewing C hahaha
	printf("memmove 이후 \n");
	memmove(str + 23, str + 17, 6); // I love Chewing C hahahahahaha
	printf("%s", str);
	
	return 0;
}
```
`memmove` 함수는 메모리의 특정한 부분의 내용을 다른 부분으로 옮겨주는 역할을 한다. 이 때 '옮긴다'고 해서 이전 공간에 있던 데이터가 사라지지는 않는다.

`memmove` 함수의 장점은 `memcpy`와 하는 일이 많이 비슷해보이지만 사실 `memcpy`와는 달리 메모리 공간이 겹쳐도 된다. 위 경우도 `str`과 복사하는 부분이 겹쳤지만 성공적으로 복사가 수행되었다.

### memcmp
```c
#include <stdio.h>
#include <string.h>

int main() {
	int arr[10] = {1, 2, 3, 4, 5};
	int arr2[10] = {1, 2, 3, 4, 5};
	
	if (memcmp(arr, arr2, 5) == 0)
		printf("arr 과 arr2 는 일치! \n"); // 일치함
	else
		printf("arr 과 arr2 는 일치 안함 \n");
	
	return 0;
}
```
`memcmp`는 두 개의 메모리 공간을 서로 비교하는 함수이다. 메모리의 두 부분을 원하는 만큼 비교할 수 있으며, 같다면 0, 다르면 0 이 아닌 값을 반환한다.
