
## const char* vs char\[\]

핵심 차이는 **`const char*`는 읽기 전용 문자열 리터럴을 가리키는 포인터**이고, **`char[]`는 메모리에 할당된 수정 가능한 문자 배열**이라는 점이다.
### const char*
`const char* str = "Hello";`를 선언하면, 컴파일러는 문자열 리터럴 `"Hello"`를 프로그램의 읽기 전용 메모리 영역에 저장한다. 변수 `str`은 그 메모리 주소를 가리키는 포인터일 뿐이다.
- **포인터 조작**: 포인터 자체를 다른 주소로 바꾸는 것은 가능하다 (`str = "Goodbye";`).
- **데이터 보호**: `const` 키워드가 붙어 있어 공유 문자열 리터럴의 데이터를 실수로 수정하는 것을 컴파일 단계에서 막아준다.

### char\[\]
`char str[] = "Hello";`를 선언하면, 컴파일러는 문자열과 널 종료 문자(`\0`)를 모두 담을 수 있는 크기(총 6바이트)의 배열을 만듭니다. 그 후 실행 시점에 해당 로컬 스택 메모리로 문자 데이터를 복사합니다.
- **배열 주소 고정**: 배열의 시작 주소 자체를 다른 문자열 주소로 바꿀 수는 없습니다 (`str = "Goodbye";`는 컴파일 에러).
- **직접 수정**: 메모리 공간을 현재 함수나 스택이 직접 소유하므로, 배열 내부의 문자들을 자유롭게 읽고 쓸 수 있습니다.

## 핵심 비교

| 특징             | `const char* str = "Hello";`          | `char str[] = "Hello";`          |
| -------------- | ------------------------------------- | -------------------------------- |
| **타입**         | 상수 문자를 가리키는 포인터                       | 수정 가능한 문자들의 배열                   |
| **메모리 위치**     | 포인터는 스택/전역; 문자열 데이터는 **읽기 전용 데이터 영역** | 배열 전체가 **스택**(또는 전역 메모리)에 할당됨    |
| **데이터 수정**     | 문자 변경 불가능 (`str[0] = 'X'` 컴파일 에러)     | 문자 변경 가능 (`str[0] = 'X'` 정상 작동)  |
| **포인터 재할당**    | 포인터 변수가 다른 문자열 주소를 가리키게 변경 가능         | 배열의 시작 주소는 고정되어 변경 불가능           |
| **sizeof 연산자** | **포인터의 크기** 반환 (시스템에 따라 4바이트 또는 8바이트) | 널 문자(`\0`)를 포함한 **배열의 전체 크기** 반환 |

## const char* vs const char\[\] vs char* vs char\[\]
|표현식|내부 문자 수정 (`str[0] = 'X';`)|주소 재할당 (`str = "New";`)|`sizeof(str)` 결과|메모리 저장 위치|
|---|---|---|---|---|
|**`const char* str`**|**불가능**|**가능**|포인터 크기 (4/8바이트)|포인터는 스택, 문자열은 읽기 전용 영역|
|**`const char str[]`**|**불가능**|**불가능**|배열 전체 크기 (널 포함)|배열 전체가 스택에 상수로 생성|
|**`char* str`** _(주의)_|**불가능 (런타임 에러)**|**가능**|포인터 크기 (4/8바이트)|포인터는 스택, 문자열은 읽기 전용 영역|
|**`char str[]`**|**가능**|**불가능**|배열 전체 크기 (널 포함)|배열 전체가 스택에 수정 가능하게 생성|


1. `const char* str = "Hello";` (가장 흔한 문자열 포인터)
	- **특징**: "읽기 전용 문자열을 가리키는 포인터"입니다.
	- **동작**: `str`이 가리키는 글자를 바꾸는 것(`str[0] = 'X'`)은 컴파일러가 막습니다. 하지만 `str`이 다른 문자열을 가리키도록 주소를 바꾸는 것(`str = "World"`)은 자유롭게 가능합니다.
2. `const char str[] = "Hello";` (읽기 전용 배열 상수)
	- **특징**: "값도 주소도 바꿀 수 없는 고정된 방"이다.
	- **동작**: 스택 메모리에 6바이트 공간이 생기고 `"Hello\0"`가 복사된 후, 데이터 수정(`str[0]='X'`)과 주소 변경(`str = "World"`)이 모두 금지된다.
3. `char* str = "Hello";` (C++에서 금지된 위험한 표현)
	- **특징**: "읽기 전용 문자열을 일반 포인터로 가리키는 방식"입니다.
	- **위험성**: 현대 C++에서는 컴파일 에러가 발생하며, C 언어에서는 컴파일은 되지만 `str[0] = 'X'`를 시도하는 순간 프로그램이 **런타임 에러(Segmentation Fault)**로 강제 종료됩니다. 문자열 리터럴 자체는 여전히 읽기 전용 영역에 있기 때문입니다. 주소 재할당(`str = "World"`)은 가능합니다.
4. `char str[] = "Hello";` (수정 가능한 로컬 배열)
	- **특징**: "글자를 마음대로 바꿀 수 있는 문자열 저장소"입니다.
	- **동작**: 실행 시점에 읽기 전용 영역에 있던 `"Hello"`를 스택에 만든 배열 방으로 그대로 복사해 옵니다. 내 메모리 공간이므로 마음대로 글자를 바꿀 수 있습니다(`str[0] = 'H'`). 단, 배열 이름 자체는 고정된 주소이므로 `str = "World"`처럼 통째로 주소를 바꾸는 대입은 불가능합니다.

## 문자열 비교

```cpp
char str_a[] = "abc";
char str_b[] = "abc";

if (str_a == str_b) {
	// 성립되지 않는다.
}
```
위 구문이 왜 성립되지 않는가?

`sizeof`와 `&`연산자를 제외하고 배열의 이름만 사용하는 경우 암묵적 형변환에 의해 포인터 타입으로 변환되어서 배열의 시작주소가 들어간다.
이때 `str_a[]`와 `str_b[]`는 저장하는 문자열이 같지만 메모리 상에서의 주소가 다르기 때문에 성립하지 않는다.
