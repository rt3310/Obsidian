## 특징 비교

| 특징           | `const char*`         | `std::string`         |
| ------------ | --------------------- | --------------------- |
| **타입 종류**    | 기본 포인터 타입 (C 스타일)     | 객체 클래스 (C++ 표준 라이브러리) |
| **메모리 할당**   | 정적 읽기 전용 메모리를 가리킴     | 힙(Heap) 영역에 동적 할당 수행  |
| **소유권**      | 데이터 소유권 없음 (단순 관찰자)   | 데이터 자체를 완전히 소유함       |
| **수정 가능 여부** | 가리키는 문자열 수정 불가        | 문자열 변경 및 크기 확장 가능     |
| **길이 계산**    | `strlen` 함수로 매번 계산 필요 | O(1) 시간 복잡도로 크기 즉시 조회 |
| **안전성**      | 버퍼 오버플로우, 대포인터 위험 존재  | 자동 경계 검사 등으로 안전함      |

## 코드 예시

```cpp
#include <iostream>
#include <string>

int main() {
    // const char* 예시
    const char* c_str = "Hello"; 
    // c_str[0] = 'h'; // 컴파일 에러: 읽기 전용 메모리 수정 불가
    
    // std::string 예시
    std::string cpp_str = "Hello";
    cpp_str += " World"; // 간편한 문자열 결합
    cpp_str[0] = 'h';    // 정상 작동: 이제 문자열은 "hello World"
}
```

## 상호 변환

- `const char*` ➔ `std::string`: 암시적 변환이 일어난다. 함수 인자에 문자열 리터럴을 전달하면 자동으로 객체가 생성된다.
- `std::string` ➔ `const char*`: `.c_str()` 멤버 함수를 직접 호출해야 한다. 주로 오래된 C API와 연동할 때 사용한다.
